# Prioridades de tareas

En las propiedades de una tarea, elige **Alta**, **Media** o **Baja** con un toque. «Sin prioridad» quita la prioridad. Las listas, la tabla y el tablero muestran esos mismos nombres.

Los datos existentes siguen siendo compatibles: Alta se guarda como 1, Media como 2 y Baja como 3. En la captura rápida se pueden seguir usando los atajos `p1`, `p2` y `p3`, respectivamente; por ejemplo, `t Llamar a Ana p1`.
