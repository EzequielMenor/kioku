# Conversar y revisar propuestas

En Asistente, el menú de conversaciones ofrece la conversación actual, una nueva conversación y la actividad. La conversación actual vive en memoria: cambiar de pantalla la conserva, pero recargar la página no. No se puede empezar otra mientras el asistente responde. En el portátil también está disponible Memoria.

Las fuentes consultadas y los cambios automáticos se pueden desplegar bajo cada respuesta. Cada cambio automático ofrece Deshacer; si el archivo cambió después, el servidor puede rechazarlo para no sobrescribirlo.

Las propuestas pendientes aparecen separadas del texto. Pulsa **Revisar** para ver los cambios exactos y después elige **Aplicar** o **Descartar**; ambos requieren confirmación. Cancelar no cambia las notas. Los errores quedan visibles en la revisión. La lista respeta los permisos del dispositivo y no aplica nada automáticamente.

El control de conexión indica si Kioku responde y si se detectan los requisitos del asistente; no demuestra que una consulta vaya a ejecutarse. Sin conexión, el móvil no envía mensajes ni resuelve propuestas, ni los guarda para más tarde.
